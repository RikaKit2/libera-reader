# 02. Архитектура слоёв страницы (Page Layer Stack)

В данном документе описывается иерархия визуальных и интерактивных слоёв страницы, правила их наложения, Z-index и маршрутизация событий мыши в GPUI Kit.

---

## 1. Эталонная модель слоёв в MuPDF (`mupdf.js`)

В веб-эталоне (`other/mupdf.js/examples/simple-viewer/viewer.js` и `style.css`) страница представляет собой контейнер с относительным позиционированием (`position: relative`), внутри которого все дочерние слои абсолютно спозиционированы (`position: absolute; left: 0; top: 0; width: 100%; height: 100%`):

```
+-------------------------------------------------------------+
|                      div.page (relative)                    |
|                                                             |
|  [Слой 1] canvas (растровое изображение страницы)           |
|  [Слой 2] svg.text (прозрачный текст для выделения мыши)    |
|  [Слой 3] div.link (кликовые прямоугольники <a> гиперссылок)|
|  [Слой 4] div.search (прямоугольники подсветки поиска)      |
+-------------------------------------------------------------+
```

### Правила событий мыши в эталоне:
1. **Слой поиска (`div.search > div`)**:
   - Имеет `pointer-events: none;` — клики и выделение мыши проходят сквозь подсветку к текстовому слою.
   - Имеет `mix-blend-mode: multiply;` — цвет подсветки гармонично умножается на буквы растра, не замазывая их намертво.
2. **Слой ссылок (`div.link`)**:
   - При обычном наведении курсор меняется на `pointer`, клик переходит по ссылке.
   - Во время выделения текста пользователем вешается класс `.do-content-select`:
     ```css
     #pages.do-content-select div.link {
         pointer-events: none;
     }
     ```
     Это предотвращает случайный переход по ссылке, если пользователь начал выделять текст мышью и курсор прошёл над ссылкой.

## 2. Архитектура слоёв в GPUI Kit (`libera-reader`)

В десктопном приложении на GPUI Kit страница реализуется через структуру `PageView` (`crates/libera-reader/src/ui/pages/book-viewer/viewport/page/mod.rs`):

```
PageView (div.flex.flex_col.items_center)
│
├── Контейнер страницы (div.relative.w(px).h(px))
│   ├── 1. PageCanvas (RenderImage растра + фон инверсии)
│   ├── 2. PageLinksLayer (прямоугольники внутренних/внешних ссылок)
│   ├── 3. PageTextLayer (кастомный Element: прозрачный текст + подсветка поиска + выделение)
│   └── 4. PageShadow (декоративная внешняя тень страницы)
│
└── 5. PageNumberBadge (номер страницы под листом книги)
```

---

## 3. Детальный разбор каждого слоя

### Слой 1: `PageCanvas` (Растр книги)
- **Ответственность**: Отображение растровой картинки страницы, декодированной из PNG/BGRA через `gpui::img(ImageSource::Render(img))`.
- **Фон**: При первой загрузке (пока картинка рендерится) рисуется скелетон/плейсхолдер цвета темы.
- **Инверсия цветов**: Если включён режим чтения `invert_colors`, растр инвертируется, а фон меняется на тёмный токен темы `cx.theme().background`.
- **События**: Не перехватывает клики (`mouse_down`), являясь фоновым холстом.

### Слой 2: `PageLinksLayer` (Гиперссылки)
- **Ответственность**: Отрисовка кликабельных областей для ссылок из `page.getLinks()`.
- **Типы ссылок**:
  - Внутренние (`PageLinkDest::Page(n)`): переход на страницу книги через обновление `BookViewerState::current_page`.
  - Внешние (`PageLinkDest::Uri(url)`): открытие ссылки в браузере системы через платформенный API.
- **Интерактивность**:
  - При наведении курсор `CursorStyle::PointingHand`.
  - Чтобы ссылки не конфликтовали с выделением текста, они реагируют строго на короткий клик, не блокируя drag-события `TextSelection`.

### Слой 3: `PageTextLayer` (Текстовый слой, выделение и поиск)
- **Ответственность**:
  1. Синхронизация с движком текстового выделения GPUI `gpui_base::TextSelection`.
  2. Отрисовка прямоугольников подсветки сквозного поиска (`DocumentSearchMatch`).
  3. Отрисовка прямоугольников выделения текста мышью (`projection.ranges()`).
  4. Прозрачные глифы для хит-тестинга курсора мыши.
- **Реализация**: Низкоуровневый `gpui::Element`, реализующий фазы `request_layout`, `prepaint` (регистрация хитбокса через `window.insert_hitbox`) и `paint` (отрисовка quad-прямоугольников через `window.paint_quad`).
- **Стилизация поиска**:
  - Активное совпадение: `primary.opacity(0.65)` с рамкой `primary`.
  - Фоновые совпадения: `primary.opacity(0.20)` с рамкой `primary.opacity(0.40)`.
  - Прямоугольники имеют скругление `px(2.0)` и рисуются ПОД прозрачными глифами текста, но НАД растровым изображением книги.

### Слой 4: `PageShadow`
- **Ответственность**: Визуальный объём листа бумаги. Накладывается поверх краёв или вокруг контейнера с помощью `box-shadow` / рамки `border-color(cx.theme().border)`.

## 4. Устранение устаревшего кода (Cleanup)

- **`page_search_layer.rs`**: В кодовой базе ранее существовал отдельный файл `crates/libera-reader/src/ui/pages/book-viewer/viewport/page/page_search_layer.rs`. Он больше не подключён в дерево рендеринга `PageView`, а вся отрисовка поиска консолидирована внутри `PageTextLayer`.
- Данный файл является мёртвым кодом и подлежит удалению при имплементации, чтобы исключить путаницу при дальнейшей поддержке.
