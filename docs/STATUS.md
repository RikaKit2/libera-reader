## 1. Что уже ПОЛНОСТЬЮ РЕШЕНО (Completed & Verified)

### 1.1. База знаний и архитектура MuPDF
- [x] Изучены эталоны `other/mupdf.js` (`simple-viewer`, `worker.js`) и `other/mupdf-webviewer` (`types.d.ts`).
- [x] Составлена 6-главная модульная архитектурная документация на русском (`docs/mupdf-architecture/ru/`) и английском (`docs/mupdf-architecture/en/`).
- [x] Устранено дублирование папок `doc/` и `docs/`, всё централизовано в `docs/`.

### 1.2. Физика масштабирования и DPI экрана
- [x] Ликвидирован жестко захардкоженный `PAGE_RENDER_DPI = 150`.
- [x] Внедрена чистая математическая формула расчёта: $\text{DPI} = 72 \times \text{zoom\_factor} \times \text{scale\_factor}$.
- [x] Реализовано **двухуровневое кэширование**: мгновенный аппаратный зум имеющейся текстуры на GPU (без белых экранов и лагов) + фоновый асинхронный дорендер в физическом DPI экрана для кристальной резкости.
- [x] В `BookViewerCache` добавлен LRU-кэш `image_dpis` для отслеживания актуальности разрешений.

### 1.3. Исправление багов текстового слоя и поиска
- [x] **Ликвидирован шрифтовой дрейф (Font Metric Mismatch)**: удалён старый эвристический fallback с системным шрифтом `Inter`, из-за которого рамка обрезала слово («Вы смогл») или налезала на соседние буквы («Вы смогли с|»).
- [x] Отрисовка подсветки переведена строго на C-движок MuPDF `search_document_text` с точными координатами `BBox`.
- [x] Активное совпадение подсвечивается токеном `cx.theme().primary.opacity(0.65)` с контрастной рамкой `primary`, пассивные — `primary.opacity(0.20)` с рамкой `primary.opacity(0.40)`.
- [x] Исключена ложная индикация «Не найдено» при наборе текста (введён признак `has_searched`).
- [x] Циклическая навигация: `Enter` / стрелка `>` для перехода вперед, `Shift+Enter` / стрелка `<` для перехода назад.
- [x] Автоматический скролл виртуального списка к странице активного совпадения (`scroll_to_item`).

### 1.4. Базовая система горячих клавиш и управление фокусом
- [x] Создан модуль `actions.rs` с 22 декларативными действиями (`actions!(book_viewer, [...])`).
- [x] Решена фундаментальная проблема неработающих клавиш в GPUI:
  - В `BookViewer` добавлен `FocusHandle`.
  - Корневой контейнер читалки подключён к дереву диспетчеризации через `.track_focus(&self.focus_handle)`.
  - Настроен автоматический захват фокуса при открытии книги и по клику мыши.
- [x] Назначены сочетания клавиш по умолчанию:
  - `Right`, `Left`, `PageDown`, `PageUp`, `Space`, `Shift+Space`, `Home`, `End` — навигация по страницам.
  - `Ctrl + F`, `F3`, `Shift + F3` — поиск.
  - `Ctrl + =`, `Ctrl + -`, `Ctrl + 0` — масштабирование.
  - `F11`, `Ctrl + Shift + F` — полноэкранный режим.
  - `Ctrl + I` — инверсия цветов (ночной режим).
  - `Ctrl + B`, `Alt + 1..4` — сайдбар и переключение вкладок.
  - Умный `Escape`: сначала закрывает поиск, а при закрытом поиске выходит в библиотеку.

### 1.5. Очистка кода и оптимизация сборки
- [x] Полностью удалён мёртвый файл `page_search_layer.rs` и вычищены неиспользуемые импорты.
- [x] Проект переведён с нестабильных git-веток на официальный релиз `gpui-kit = "0.6.4"` с Crates.io.
- [x] В корневом `Cargo.toml` настроены оптимизации `[profile.dev.package]` (`opt-level = 3` для тяжелых библиотек).
- [x] Оптимизирован профиль компиляции: `debug = "line-tables-only"` и `split-debuginfo = "unpacked"`.
- [x] Очищено 14 ГБ устаревшего кэша сборки, стабильный тулчейн Rust 1.98.1 компилирует проект быстро.

## 2. Что находится В ПРОЦЕССЕ и предстоит решить в первую очередь (Next Steps)

Задачи подробно расписаны в плане [`docs/superpowers/plans/2026-09-20-keybindings-and-controls.md`](superpowers/plans/2026-09-20-keybindings-and-controls.md):

### 2.1. Оживление зума «По ширине» (`FitWidth`) и «По высоте» (`FitPage`) (Task 2)
- **Проблема сейчас**: если в выпадающем списке шапки выбрать «По ширине» или «По высоте», в коде возвращается `None` и ничего не происходит.
- **Что нужно сделать**:
  - Реализовать расчёт `calculate_fit_width(viewport_w, page_w)` и `calculate_fit_page(viewport_h, page_h)`.
  - Автоматически пересчитывать масштаб при изменении размеров окна читалки.
  - Добавить плавный зум колёсиком мыши с зажатым `Ctrl` (`Ctrl + MouseWheel`) в `scroll_container.rs`.

### 2.2. Модель хранения кастомных клавиш в базе данных (Task 3)
- **Что нужно сделать**:
  - Создать структуру `KeybindingsConfig` в `crates/libera-reader/src/db/models/settings/keybindings.rs`.
  - Реализовать проверку конфликтов сочетаний клавиш (`find_conflict`).
  - Добавить поле `keybindings` в модель `Settings` с сохранением в `native_db`.

### 2.3. Интерактивный редактор клавиш в меню Настроек (Task 4)
- **Что нужно сделать**:
  - Добавить вкладку «Горячие клавиши» (Keybindings) в окно `Settings`.
  - Список действий, сгруппированный по категориям (Навигация, Просмотр, Поиск, Аудио, Система).
  - Компонент `KeyRecorder`: модальное окно/поповер, перехватывающий нажатие клавиш пользователя.
  - Кнопка сброса отдельного сочетания на заводское значение и кнопка «Сбросить все».
  - Динамическая перепривязка в окне через `cx.bind_keys(...)`.

### 2.4. Виртуализация вкладки эскизов страниц (`ThumbnailsView`) (Task 5)
- **Проблема сейчас**: для 600-страничной книги создаётся 600 объектов `ThumbnailCard` одновременно в обычном `div()`, что грузит память и вызывает фризы.
- **Что нужно сделать**:
  - Перенести архитектуру из `BooksGrid`:
    - `BoundedCache` с вызовом `flush_evictions(cx)` (освобождение текстур из GPU атласа).
    - Фоновый параллельный загрузчик с `Semaphore`.
    - Атомарные границы `visible_start` / `visible_end` для отмены прокрученных страниц.
    - Виртуальный список `v_virtual_list`: в памяти рендерятся только видимые 4–8 карточек.
