### 1.2. Редактор горячих клавиш в Настройках (Custom Keybindings Editor)
Пользовательский интерфейс настройки клавиатурных комбинаций в меню настроек:
- **Раздел настроек**: Вкладка `Keybindings` («Горячие клавиши») в окне `Settings`.
- **Группировка по категориям**: Навигация, Масштаб, Поиск, Вид, Сайдбар, Озвучка, Система.
- **Интерфейс назначения клавиш (Key Recorder)**:
  - Клик по кнопке сочетания клавиш переводит строку в режим ожидания нажатия (`Press desired keys...`).
  - Перехват модификаторов (`Ctrl`, `Alt`, `Shift`, `Super`) и основной клавиши.
  - Валидация конфликтов: если комбинация уже используется другим действием, выводится предупреждение с вопросом о перезаписи.
- **Сброс по умолчанию**:
  - Кнопка сброса конкретного сочетания на заводское значение.
  - Глобальная кнопка «Сбросить все сочетания по умолчанию».
- **Хранение**:
  - Сохранение кастомных привязок в модель настроек `KeybindingsSettings` через `native_db`.
  - При запуске приложения и при сохранении настроек вызывается динамическая перепривязка `cx.bind_keys(...)`.

### 1.4. Оптимизация эскизов (`ThumbnailsView`) на базе архитектуры `BooksGrid`
- **Переиспользование готовой архитектуры `BooksGrid`**:
  - LRU-кэш `BoundedCache` с вызовом `flush_evictions(cx)` (`cx.drop_image`), чтобы вытесненные миниатюры страниц освобождали текстурную память GPU.
  - Параллельный фоновый загрузчик (`spawn_background_loader`) с ограничением потоков через `tokio::sync::Semaphore(threads)`.
  - Атомарные границы `visible_start` / `visible_end` для мгновенной отмены рендеринга страниц, которые пользователь быстро проскроллил.
  - Коалесценция уведомлений (`coalesced notify`): слияние десятков всплесков загрузки в один кадр перерисовки вместо лавинных перерисовок.
  - Виртуализация сетки через `v_virtual_list`: в памяти существуют только 4–8 карточек, попадающих на экран сайдбара.
  - Мгновенное открытие вкладки даже для книг на 2000+ страниц без фризов и утечек VRAM.

### 1.5. Боковая панель результатов поиска (`SidebarTab::Search`)
- Полноценная вкладка поиска в сайдбаре по образцу MuPDF WebViewer (`Panel::TEXT_SEARCH`):
  - Показывает список всех найденных совпадений по книге.
  - Отображает номер страницы и текстовый сниппет с контекстом вокруг найденной фразы.
  - Клик по элементу списка мгновенно переносит пользователя на нужную страницу и центрирует совпадение.


### 1.6. Сжатие в WebP (обложки и страницы), 0-swap BGRA декодирование и загрузка mutool — [x] ЗАВЕРШЕНО
- **Сжатие в WebP (Quality 80.0 / 85.0)**: уменьшение размера обложек до 1.5–9 КБ и страниц до 150–300 КБ (экономия 60–67% по сравнению с JPEG и до 10–20 раз по сравнению с PNG).
- **0-Swap нативное BGRA-декодирование**: чтение WebP напрямую в память GPUI через `libwebp_sys2::WebPDecodeBGRAInto`, ликвидирован попиксельный цикл `px.swap(0, 2)`.
- **Асинхронная загрузка в UI минуя БД**: чтение напрямую с файловой системы без захвата транзакционных локов `redb` / `native_db`.
- **Официальный релиз Artifex MuPDF для Windows**: скачивание стабильного бинарника `mupdf-1.28.5-windows.zip` с GitHub и централизованный резолвер `mutool::mutool_command()`.

## 2. Среднесрочные планы (Medium Term)

1. **Двухстраничный разворот (Two-Page Spread / Book Mode)**:
   - Отображение страниц парами (чётная + нечётная), как в физической бумажной книге.
   - Возможность сдвига обложки (первая страница отображается одиночно).
2. **Типографика EPUB**:
   - Настройки шрифта, размера текста, межстрочного интервала и выравнивания для формата EPUB.
3. **История и прогресс чтения**:
   - Автоматическое сохранение последней открытой страницы и точной позиции скролла для каждой книги.
