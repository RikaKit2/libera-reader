# Экосистема утилит CLI для анализа профилей DHAT (`dhat-heap.json`)

В экосистеме Rust и Valgrind для анализа файлов профилирования памяти `dhat-heap.json` в терминале и консольных пайплайнах сложился стандартный стек инструментов:

---

## 1. Связка инструментов для терминала (Рекомендованный стек)

### A. Конвертер профилей: `dhat-to-flamegraph`
* **Крейт:** [`dhat-to-flamegraph`](https://crates.io/crates/dhat-to-flamegraph) (автор Yoshua Wuyts).
* **Назначение:** Читает сырой `dhat-heap.json` и преобразует его в формат **folded stack traces** (стандартный формат для флеймграфов и TUI-утилит) либо напрямую в интерактивный SVG.
* **Установка:**
  ```bash
  cargo install dhat-to-flamegraph
  ```
* **Режимы анализа (флаг `-m, --metric`):**
  - `-m heap-max` — **Пиковое потребление памяти** (показывает, кто вызвал всплеск ОЗУ).
  - `-m end` — **Утечки памяти** (показывает объекты, оставшиеся в куче перед выходом).
  - `-m total` — Полный суммарный объём всех выделений за сессию.
  - `-u blocks` — Анализ «churn» (количество блоков/аллокаций вместо байтов).

---

### B. Интерактивный терминальный TUI-просмотрщик: `flamelens`
* **Пакет в Nixpkgs:** `pkgs.flamelens` (написан на Rust с `ratatui`).
* **Крейт:** [`flamelens`](https://crates.io/crates/flamelens).
* **Назначение:** Полноценный терминальный интерактивный интерфейс для исследования флеймграфов (навигация стрелками, поиск, зум в стеки вызовов, процентное распределение памяти прямо в консоли без браузера).
* **Установка на NixOS:**
  ```bash
  # Разовый запуск:
  nix-shell -p flamelens
  # Или добавление в configuration.nix / home-manager:
  pkgs.flamelens
  ```

---

### C. Готовые команды и пайплайны в терминале:

```bash
# 1. Интерактивный разбор ПИКА памяти в терминале:
dhat-to-flamegraph -f folded -m heap-max dhat-heap.json | flamelens

# 2. Интерактивный поиск УТЕЧЕК памяти (объекты перед выходом):
dhat-to-flamegraph -f folded -m end dhat-heap.json | flamelens

# 3. Интерактивный анализ частоты аллокаций (churn):
dhat-to-flamegraph -f folded -u blocks dhat-heap.json | flamelens

# 4. Генерация SVG флеймграфа для браузера / отчётов:
dhat-to-flamegraph -f svg -m heap-max dhat-heap.json > heap-peak.svg
```

---

## 2. Дополнительные утилиты

* **`jless` (`pkgs.jless`)** — Vim-подобный интерактивный пейджер JSON с поддержкой сворачивания узлов, подсветки синтаксиса и поиска по регулярным выражениям. Идеален для мгновенной инспекции сырых блоков и строк `dhat-heap.json`.
* **`scripts/dhat_summary.py`** — локальный легковесный скрипт в репозитории для мгновенной выдачи текстовой сводки с процентами по подсистемам для агентов и разработчиков.
